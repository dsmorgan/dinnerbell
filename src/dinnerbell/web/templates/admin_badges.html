Counts for each tier

Every badge uses the same five counts. Each one needs a higher count than the one before it, and none can be above 10,000. The counts start at 1, 10, 50, 100, and 200. Lowering a count awards the tier to anyone who already has the count, quietly: nobody is announced a badge for a change of rules. Raising a count takes nothing away from anyone who already earned the tier.

Imports never delete. Items that match by name are updated; everything else stays as it is. If any entry has a problem, nothing is saved.

File format

The format is described in docs/catalog-format.md in the Dinnerbell source. A short example:

version: 1
tags:
  cuisine: [Thai, Mexican]
  other: [spicy]
restaurants:
  - name: Siam Garden
    cuisine: [Thai]
    tags: [spicy]
    modes: [pickup, delivery]
    meals: [lunch, dinner]
    url: https://example.com/menu
home_meals:
  - name: Chicken tacos
    cuisine: [Mexican]
    servings: 6
    cooks: [you@example.com]

meals can list breakfast, lunch, and dinner. Leave it out for lunch and dinner.

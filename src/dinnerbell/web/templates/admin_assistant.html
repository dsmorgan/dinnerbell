The assistant answers members' questions with Anthropic's {{ model }} model, acting only as the member asking, never with admin rights. It changes nothing until they confirm. Anthropic gets the conversation, what the assistant looks up, and active members' names, never emails or Slack IDs. A member's own preferences, ratings, and dietary needs, which can reveal health or religion, go only when they ask in private{% if values['memory'] %}, and, with Memory on, every member's remembered tastes go with every request, and housemates' Preferences go in private when someone asks{% endif %}.

How long a conversation is kept after its last message, 0 to {{ limits['hours'][1] }} (a week). At 0, each message stands alone. Lowering it deletes older ones at once.

Before a conversation is deleted, a rollup keeps short notes from each member's own messages about their tastes and habits, up to 20 each, and the assistant reads every member's notes when it answers anyone, in direct messages, on the Assistant page, and in channel threads. It also reads housemates' Preferences (levels, vetoes, dietary needs, and I can usually) when a member asks in private. Memory never changes ranking or filters. Each member sees and removes their own notes on the Assistant page. It adds API cost, and needs Conversation hours above 0. Turning it off stops new notes and sends none; the notes it kept stay until you clear them below.

The model that writes Memory's notes; claude-haiku-5-5 is recommended. Each rollup call counts toward the monthly cap, under the member whose messages it reads, and a failed try keeps its whole reservation, about $0.80 with claude-opus-5-5.

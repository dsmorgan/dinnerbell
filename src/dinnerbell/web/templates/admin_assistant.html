The assistant answers members' questions in plain language, using Anthropic's {{ model }} model. It acts only as the member it's answering, never with admin rights, and changes nothing by itself. Dinnerbell sends Anthropic the conversation and what the assistant looks up, with members shown as "Member 1", "Member 2", and so on: never names, emails, preferences, vetoes, or anyone's ratings. The one exception is a member's own preferences, vetoes, ratings, feedback, and away days, which it sends only when that member asks about them in their own conversation, on the Assistant page or in a direct message. For a call a member coordinates, in the same places, it sends who's in, by those labels, with the roles they offered: never anyone's vote, maybe, or out. To answer questions about what the household has eaten, it sends each item's household hint, such as "Well liked", the same words every member sees on Catalog.

The web app lets members add Dinnerbell to their phone's Home Screen and choose, on Preferences, whether Dinnerbell reaches them in Slack, the web app, or both. A member without a Slack account can only use the web app. While it's on, Slack skips direct messages to members who chose the web app, instead of failing to send them. Channel posts still go to the channel.

{#- Part 1 of #138 only: delete this warning once push notifications and code sign-in exist. -#}

Not finished yet. Push notifications and signing in with a code aren't built yet. Until they are, members on Web app, including every member without a Slack account, get no direct messages at all: no reminders, no roles, no hand-offs. Turn this on only to try it out.

Off by default. While it's off, members see no change, Slack delivery is unchanged, and the app's pages don't exist. Turning it off keeps each member's choice for when it's on again.

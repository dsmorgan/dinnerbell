Import with `{% from "_badge.html" import ... %}`. badge_art(key, tier, locked=False, decorative=False) Just the picture. `key` is a BadgeKey value ("chef"), `tier` a Tier value ("gold"). `locked` draws a soft gray placeholder. `decorative` hides it from screen readers; use it where the name and tier are in text beside it. badge_chip(key, tier) A badge as an inline picture and a "Chef · Gold" label: the form for lists of awards. badge_row(p) One `domain.badges.Progress`: picture, name, tier or "Not earned yet", and progress to the next tier. Slack and App Home reuse the names, not the markup: `web.badge_art.standalone_svg(key, tier)` returns the same art as a still SVG file to render as a PNG. -#} {% macro badge_art(key, tier, locked=False, decorative=False) -%} {{ badge_svg(key, tier, locked=locked, decorative=decorative) }} {%- endmacro %} {% macro badge_chip(key, tier) -%} {{ badge_art(key, tier, decorative=True) }}{{ badge_name(key) }} · {{ tier|capitalize }} {%- endmacro %} {% macro badge_row(p) -%} {% set key = p.badge.key.value %} {% set locked = p.tier is none %}

# Security policy

## Report a vulnerability

Report a vulnerability privately through GitHub: open a [private vulnerability report](https://github.com/dsmorgan/dinnerbell/security/advisories/new) (the **Security** tab, then **Report a vulnerability**). Don't open a public issue, pull request, or discussion for a security problem.

Include the version you run (`/healthz` reports it), what an attacker can do, and the steps to reproduce it.

You can expect an acknowledgment within 7 days. A fix ships as a new release, and the security advisory is published after the release, with credit to you unless you'd rather stay anonymous.

## Supported versions

Only the [latest release](https://github.com/dsmorgan/dinnerbell/releases/latest) gets security fixes. Upgrade to it before you report a problem, if you can.
